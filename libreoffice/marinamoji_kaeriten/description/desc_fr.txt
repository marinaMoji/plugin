marinaMoji — Make room for character

Met en forme les kaeriten Unicode (signes de lecture kanbun, U+3190–U+319F) dans LibreOffice Writer sous forme de glyphes compacts. Saisissez le texte source (par ex. 說㆒㆑者), puis utilisez la barre d’outils marinaMoji pour Rendre, Annuler le rendu, Copier le texte brut ou Basculer la page verticale.

Prend aussi en charge le warichū (割注) : sélectionnez uniquement le texte de la note, puis Appliquer. Retirer fonctionne aussi avec le curseur dans l’annotation (pas tout le paragraphe ; pas de propriétés UNO de parenthèses ; coupure et taille gérées par Writer).

Ruby de groupe : sélectionnez le texte de base → Appliquer le ruby → saisissez la lecture (alignement par défaut LEFT, natif Writer). Retirer fonctionne aussi avec le curseur. Le texte de base est conservé. Pas d’imbrication avec le warichū.

Tate-chū-yoko (縦中横) : sélectionnez un court run latin/chiffres → Appliquer (rotation 90° + ajustement à la ligne). Approximation Writer, pas la fonction Word. Pas avec le warichū sur le même span.

Points d’emphase (圏点) : sélectionnez le texte → Appliquer (défaut du document, sésame noir) ou menu pour disque / cercle / point, Retirer, ou Définir le signe par défaut. Changer le défaut ne réécrit pas les marques existantes.

Jidori (字取り) : sélectionnez un court run japonais → Appliquer le jidori → indiquez N cadratins. Expansion via l’interlettrage ; compression via l’échelle de largeur en horizontal seulement (refusée en vertical). Supprimer restaure l’échelle/l’interlettrage antérieurs si les métadonnées marinaMoji sont présentes. Approximation — pas l’équivalent de Fit Text Word.

À propos de marinaMoji : le logo carré à gauche de la barre d’outils ouvre un guide illustré hors ligne sur les outils typographiques et leur lien avec la méthode de saisie.

Inspecteur typographique japonais (lecture seule) : Vérifier la typographie japonaise affiche les réglages de composition et quelques avis prudents. Ne modifie pas le document et ne prétend pas à une conformité JLREQ complète.

Fonctionne hors ligne. Aucune télémétrie. L’IME marinaMoji n’est pas requis à l’exécution (toute saisie produisant les marques Unicode convient). LibreOffice 6.4 ou plus récent.
