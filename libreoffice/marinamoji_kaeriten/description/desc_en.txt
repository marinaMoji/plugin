marinaMoji — Make room for character

Formats Unicode kaeriten (Kanbun reading marks, U+3190–U+319F) in LibreOffice Writer as compact rendered glyphs. Type source text such as 說㆒㆑者, then use the marinaMoji toolbar to Render, Unrender, Copy plain text, or Toggle vertical page.

Also formats native warichū (割注): select the note text (not the whole paragraph), then Apply warichū. Remove warichū works with a selection or with the caret inside the annotation. Uses Writer’s character-span combine — no UNO bracket props (host owns line split and size).

Native group-ruby (振り仮名): select base text → Apply ruby → enter the reading (default alignment LEFT — Writer-native, stable beside warichū). Remove ruby works from a selection or caret inside the ruby span. Base characters are preserved. Do not nest on warichū.

Native tate-chū-yoko (縦中横): select a short Latin/digit run → Apply (CharRotation 90° + fit to line). Remove clears rotation. Approximation of 縦中横 — not Word’s dedicated feature. Refuses warichū on the same span.

Native emphasis marks (圏点・傍点): select text → Apply (document default, 黒ゴマ / accent) or open the emphasis menu for 黒丸 / 白丸 / 点, Remove, or Set default. Passage marks are ordinary CharEmphasis; changing the document default does not rewrite existing marks.

Jidori (字取り): select a short Japanese run → Apply jidori → enter N character cells. Expands with Spacing; compresses with Scale width in horizontal writing only (vertical compress is refused). Remove restores prior scaling/spacing when marinaMoji’s bookmark/metadata is present. Approximate fit — not Word Fit Text.

About marinaMoji: the square logo at the left of the toolbar opens an offline illustrated guide to the typography tools and how they complement the marinaMoji input method.

Japanese Typography Inspector (read-only): Inspect Japanese Typography reports Asian composition settings and a few conservative advisories. It does not modify the document and does not claim full JLREQ validation.

Works offline. No telemetry. Does not require the marinaMoji IME at runtime (any input that produces the Unicode marks is fine). LibreOffice 6.4 or newer.
